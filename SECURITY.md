# Security Policy

## Scope

FactTTL is in design stage and has no released product or supported versions. This policy will be updated when releases begin.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** feature in the repository's Security tab to send a private advisory to the maintainers. If that feature is unavailable, contact the repository owner privately through the email address listed on their GitHub profile and include “FactTTL security report” in the subject.

Include the affected component or document, steps to reproduce, potential impact, and any suggested mitigation. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Do not include secrets or personal data in a report unless necessary; redact them where possible.

## Response

Maintainers will acknowledge reports as soon as reasonably possible, assess severity and scope, and coordinate disclosure with the reporter. Response times and supported-version commitments will be defined before the first release.
